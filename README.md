# 🚀 Team Task Manager

A full-stack web application for managing projects and tasks with role-based access control.

---

## 🔗 Live Demo
👉 http://team-task-manager79.netlify.app/

---

## 📦 GitHub Repository
👉 https://github.com/himanshu79854/team-task-manager

---

## ✨ Features

- 🔐 User Authentication (Signup/Login)
- 👥 Role-Based Access (Admin & Member)
- 📁 Project Management
- ➕ Add/Remove Members
- ✅ Task Management (Create, Update, Delete)
- 📊 Task Status Tracking (Todo, In Progress, Done)
- 🎨 Clean UI with Tailwind CSS

---

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- Tailwind CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB Atlas

**Deployment:**
- Backend: Railway
- Frontend: Netlify

---

## 🧠 How It Works

- Admin creates projects and manages members
- Members can access only assigned projects
- Tasks are linked to projects and updated dynamically
